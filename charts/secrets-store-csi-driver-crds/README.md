# secrets-store-csi-driver-crds

A Helm chart to install the CustomResourceDefinitions for Secrets Store CSI driver for Kubernetes secrets.

CRDs are copied verbatim from [kubernetes-sigs/secrets-store-csi-driver](https://github.com/kubernetes-sigs/secrets-store-csi-driver)
at tag [`v1.6.1`](https://github.com/kubernetes-sigs/secrets-store-csi-driver/tree/v1.6.1) (commit `0e4ceeb734246e1de5267d8968023a3c8dcff39a`),
path(s) `config/crd/bases`, and rendered as regular Helm templates so that
`helm upgrade` updates them (Helm's own `crds/` directory never upgrades).

## Install

```sh
helm install secrets-store-csi-driver oci://ghcr.io/dsohqlab/helm-charts/secrets-store-csi-driver-crds --version <version>
```

Chart `version` equals the upstream version it ships; `appVersion` is always the exact upstream version.
Installing requires Kubernetes >=1.16.0.

### Already have these CRDs?

If the CRDs were installed by the operator chart or `kubectl apply`, Helm refuses with
"rendered manifests contain a resource that already exists". Either let Helm adopt them:

```sh
helm install secrets-store-csi-driver oci://ghcr.io/dsohqlab/helm-charts/secrets-store-csi-driver-crds --version <version> --take-ownership   # Helm >= 3.17
```

or, on older Helm, hand them over first (replace `<release>` and `<namespace>`):

```sh
kubectl annotate crd secretproviderclasses.secrets-store.csi.x-k8s.io secretproviderclasspodstatuses.secrets-store.csi.x-k8s.io \
  meta.helm.sh/release-name=<release> meta.helm.sh/release-namespace=<namespace> --overwrite
kubectl label crd secretproviderclasses.secrets-store.csi.x-k8s.io secretproviderclasspodstatuses.secrets-store.csi.x-k8s.io \
  app.kubernetes.io/managed-by=Helm --overwrite
```

## Values

| Key | Type | Default | Description |
|-----|------|---------|-------------|
| `annotations` | object | `{}` | Extra annotations added to every CRD. |
| `labels` | object | `{}` | Extra labels added to every CRD. |
| `keepOnUninstall` | bool | `true` | Add `helm.sh/resource-policy: keep` so CRDs (and all their custom resources) survive `helm uninstall`. |

Unknown keys are rejected (`values.schema.json`).
