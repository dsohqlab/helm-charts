# aws-load-balancer-controller-crds

A Helm chart to install the CustomResourceDefinitions for AWS Load Balancer Controller.

CRDs are copied verbatim from [kubernetes-sigs/aws-load-balancer-controller](https://github.com/kubernetes-sigs/aws-load-balancer-controller)
at tag [`v3.6.2`](https://github.com/kubernetes-sigs/aws-load-balancer-controller/tree/v3.6.2) (commit `d19307ccb61acb577ebeb9ffbf20d19047e7a275`),
path(s) `config/crd/bases`, and rendered as regular Helm templates so that
`helm upgrade` updates them (Helm's own `crds/` directory never upgrades).

## Install

```sh
helm install aws-load-balancer-controller oci://ghcr.io/dsohqlab/helm-charts/aws-load-balancer-controller-crds --version <version>
```

Chart `version` equals the upstream version it ships; `appVersion` is always the exact upstream version.
Installing requires Kubernetes >=1.25.0.

### Already have these CRDs?

If the CRDs were installed by the operator chart or `kubectl apply`, Helm refuses with
"rendered manifests contain a resource that already exists". Either let Helm adopt them:

```sh
helm install aws-load-balancer-controller oci://ghcr.io/dsohqlab/helm-charts/aws-load-balancer-controller-crds --version <version> --take-ownership   # Helm >= 3.17
```

or, on older Helm, hand them over first (replace `<release>` and `<namespace>`):

```sh
kubectl annotate crd albtargetcontrolconfigs.elbv2.k8s.aws ingressclassparams.elbv2.k8s.aws targetgroupbindings.elbv2.k8s.aws \
  meta.helm.sh/release-name=<release> meta.helm.sh/release-namespace=<namespace> --overwrite
kubectl label crd albtargetcontrolconfigs.elbv2.k8s.aws ingressclassparams.elbv2.k8s.aws targetgroupbindings.elbv2.k8s.aws \
  app.kubernetes.io/managed-by=Helm --overwrite
```

## Values

| Key | Type | Default | Description |
|-----|------|---------|-------------|
| `annotations` | object | `{}` | Extra annotations added to every CRD. |
| `labels` | object | `{}` | Extra labels added to every CRD. |
| `keepOnUninstall` | bool | `true` | Add `helm.sh/resource-policy: keep` so CRDs (and all their custom resources) survive `helm uninstall`. |

Unknown keys are rejected (`values.schema.json`).

## CRDs

| CRD | Kind | Group | Scope | Versions |
|-----|------|-------|-------|----------|

| `ingressclassparams.elbv2.k8s.aws` | IngressClassParams | elbv2.k8s.aws | Cluster | **v1beta1** |
| `targetgroupbindings.elbv2.k8s.aws` | TargetGroupBinding | elbv2.k8s.aws | Namespaced | v1alpha1, **v1beta1** |
